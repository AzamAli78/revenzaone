# Revenza One website

Static, zero-dependency site (Node 18+) plus one serverless endpoint for the contact form.

## Run locally
```bash
npm start          # builds to ./dist and serves http://localhost:4173
```

## Edit content
Everything editable lives in `site.config.mjs`: contact details, social links, services, prices, bundles, portfolio, about text. After editing, run `npm run build`.
Any `[INSERT ...]` value is hidden from the site until you fill it in.

- **WhatsApp number**: digits with country code, e.g. `919876543210`. Until set, the WhatsApp buttons open WhatsApp without a recipient.
- **Add a portfolio project**: add an object to `portfolio` (set `kind: 'Client'` only for real, approved work; `image` can point to a real screenshot in `assets/img/portfolio/`).
- **Images/logo**: `assets/img/`.

## Deploy (Cloudflare Pages, free and allowed for business sites)
1. In Cloudflare: **Workers & Pages → Create → Pages → Connect to Git**, pick this GitHub repo.
2. Build settings: framework preset **None**, build command `node build.mjs`, build output directory `dist`.
3. Add variables (Settings → Variables and Secrets, see `.env.example`): `SITE_URL`, `RESEND_API_KEY`, `CONTACT_TO_EMAIL`, `CONTACT_FROM_EMAIL`. Redeploy after adding them.
4. Create a free Resend account, verify your sending domain, and create an API key.
5. Custom domain: add the domain to Cloudflare (free plan), switch the nameservers at your registrar to the two Cloudflare gives you, then in the Pages project open **Custom domains** and add both `revenzaone.site` and `www.revenzaone.site`.

How it fits together: `functions/api/contact.js` is the Cloudflare handler for the form, `api/contact.js` is the same handler for the local preview (and Vercel), and both use `lib/contact.js`. The build writes `dist/_headers` for security and cache headers. `vercel.json` is only used if you deploy to Vercel instead.

Until the Resend variables are set, the contact form returns an honest "not connected yet" error and points visitors to WhatsApp. It never shows a fake success message.

## SEO
Per-page titles, descriptions, canonical and Open Graph tags, Organization/ProfessionalService JSON-LD, `sitemap.xml` and `robots.txt` are generated by `build.mjs`. Set `SITE_URL` to your real domain. Set `site.seoLocation` in the config later for location-specific schema.

## 30-second explainer film
Source lives in `film/` (excluded from Vercel deploys):
- `film.html`: the whole film as one 1920x1080 page; every frame is computed by `window.seek(t)`.
- `audio.js`: the soundtrack, written in code (Web Audio API, 120 BPM).
- `render.py`: renders with Playwright + Microsoft Edge and the bundled ffmpeg (`pip install playwright imageio-ffmpeg pillow`).

```bash
cd film
python render.py prep     # extract the AI video frames (once)
python render.py stills   # one frame per beat, for review
python render.py audio    # build/soundtrack.wav
python render.py video    # 60 fps, 3 blended subframes per frame (about 15 min)
python render.py mux      # revenza-one-explainer.mp4
```
`r-mark.png` is the logo mark with its arrow cut out; the arrow is redrawn as a vector so it can fly through every scene.
